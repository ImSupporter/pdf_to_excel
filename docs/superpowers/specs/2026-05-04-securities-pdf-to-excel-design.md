# 증권 거래내역 PDF → 엑셀 변환기 설계 문서

**날짜:** 2026-05-04  
**상태:** 승인됨

---

## 1. 개요

여러 증권사의 거래내역서 PDF를 읽어 엑셀 파일로 변환하는 Windows GUI 애플리케이션.  
현재 미래에셋증권, 삼성증권을 지원하며, 새 증권사를 쉽게 추가할 수 있는 플러그인 구조로 설계한다.

---

## 2. 기술 스택

| 역할 | 라이브러리 |
|---|---|
| GUI | PyQt6 |
| PDF 파싱 | PyMuPDF (fitz) |
| 엑셀 출력 | openpyxl |
| 배포 | PyInstaller (`--onefile --windowed`) |
| Python 버전 | 3.11+ |

---

## 3. 아키텍처

```
PDF 파일들 (복수)
    ↓
[PDF 로더] — 비밀번호 처리, PyMuPDF로 텍스트/레이아웃 추출
    ↓
[브로커 감지기] — PDF 내 키워드로 증권사 자동 식별
    ↓
[브로커 파서] — 증권사별 파싱 로직 (플러그인 구조)
  ├── MiraeAssetParser  (미래에셋증권)
  ├── SamsungParser     (삼성증권)
  └── UnknownParser     → [컬럼 매핑 GUI] 로 넘김
    ↓
[데이터 정규화기] — 각 파서 결과를 공통 스키마로 변환
    ↓
[컬럼 선택기] — 사용자가 통합 시트에 포함할 컬럼 선택
    ↓
[엑셀 익스포터] — Sheet1: 통합, Sheet2+: 증권사별 원본
    ↓
output.xlsx
```

**핵심 원칙:** 새 증권사 추가 = 새 파서 클래스 하나만 작성

## 4. 파일 구조

```
save_hj/
├── main.py                  # 앱 진입점
├── requirements.txt
├── ui/
│   ├── main_window.py       # 메인 윈도우
│   ├── password_dialog.py   # 비밀번호 입력 팝업
│   ├── column_select.py     # 컬럼 선택 체크박스 화면
│   └── mapping_dialog.py    # 미인식 증권사 컬럼 매핑 팝업
├── parsers/
│   ├── base.py              # BaseParser 추상 클래스
│   ├── mirae_asset.py       # 미래에셋증권 파서
│   └── samsung.py           # 삼성증권 파서
└── core/
    ├── loader.py            # PDF 로드 & 비밀번호 처리
    ├── detector.py          # 브로커 자동 감지
    ├── normalizer.py        # 공통 스키마 변환
    └── exporter.py          # 엑셀 파일 생성
```

## 5. UI 화면 구성

### 메인 윈도우

```
┌─────────────────────────────────────────────┐
│  증권 거래내역 → 엑셀 변환기                    │
├─────────────────────────────────────────────┤

│  ┌─────────────────────────────────────────┐ │
│  │ 파일명              증권사    상태        │ │
│  │ 거래내역증명서.pdf   미래에셋  ✓ 인식됨   │ │
│  │ 거래내역확인서.pdf   삼성증권  ✓ 인식됨   │ │
│  └─────────────────────────────────────────┘ │
│                                              │

│                                              │
│  저장 위치: [경로 표시____________] [찾아보기]   │
│                                              │
│            [변환 시작]                        │
│  ─────────────────────────────────────────  │
│  진행상황: ████████░░ 80%                     │
└─────────────────────────────────────────────┘
```

### 비밀번호 입력 팝업
- 파일 추가 시 자동 표시
- 이전에 입력한 비밀번호가 입력창에 힌트로 표시
- 비워두면 비밀번호 없는 PDF로 처리

### 컬럼 매핑 팝업 (미인식 증권사)
- PDF에서 추출된 헤더 목록 표시
- 각 헤더에 대해 표준 필드 드롭다운으로 매핑 지정

## 6. 데이터 모델

### 공통 스키마 (Transaction)

| 표준 필드 | 설명 | 미래에셋 원본 | 삼성증권 원본 |
|---|---|---|---|
| `date` | 거래일자 | 거래일자 | 거래일자 |
| `type` | 거래종류 | 거래종류 | 거래명 |
| `ticker` | 종목코드 | 종목번호 | 종목명에서 파싱 |
| `name` | 종목명 | 종목명 | 종목명 |
| `quantity` | 수량 | 거래수량 | 거래수량 |
| `price` | 단가 | 단가 | 거래단가 |
| `amount` | 거래금액 | 거래금액 | 거래금액 |
| `fee` | 수수료 | 수수료 | 수수료/Fee |
| `tax` | 세금 | 제세금합 | 제세금/대출이자 |
| `balance` | 잔액 | 예수금잔액 | 현금잔액 |
| `broker` | 증권사명 | 자동 | 자동 |

- 매핑 안 되는 필드는 `broker_*` 접두사로 통합 시트에 추가 가능

### 엑셀 출력 구조
- **Sheet 1 (통합):** 모든 거래를 공통 스키마로 정규화, 사용자가 선택한 컬럼만 출력
- **Sheet 2+ (증권사별):** PDF 원본 컬럼 구조 그대로 출력

## 7. 에러 처리

| 상황 | 처리 방식 |
|---|---|
| 비밀번호 틀림 | 팝업으로 재입력 요청 |
| 증권사 자동 인식 실패 | 컬럼 매핑 GUI로 안내 |
| PDF 파싱 중 일부 행 실패 | 해당 행 스킵 후 완료 시 경고 목록 표시 |
| 출력 파일이 이미 열려있음 | 파일 닫고 재시도 안내 팝업 |

## 8. 확장성 — 새 증권사 추가 방법

```python
class NewBrokerParser(BaseParser):
    BROKER_NAME = "키움증권"
    DETECTION_KEYWORDS = ["키움증권", "계좌번호"]  # 자동 감지용 키워드

    def parse(self, pages) -> list[Transaction]:
        ...
```

브로커 감지기는 등록된 모든 파서를 순회하며 키워드 매칭.  
새 파서는 `parsers/__init__.py`의 `PARSERS` 리스트에 명시적으로 등록하면 감지 대상에 포함된다.

```python
# parsers/__init__.py
from .mirae_asset import MiraeAssetParser
from .samsung import SamsungParser

PARSERS = [MiraeAssetParser, SamsungParser]  # 새 파서는 여기에 추가
```
